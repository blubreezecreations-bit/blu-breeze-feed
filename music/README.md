# Blu Breeze music library

Royalty-free tracks for Reels. Every file here is published at:
https://blubreezecreations-bit.github.io/blu-breeze-feed/music/<file-name>

Add tracks by dragging MP3 files into this folder on github.com (Add file → Upload files).
Name them by mood, e.g. `lofi-calm-01.mp3`, `winter-acoustic-01.mp3`, `piano-ambient-01.mp3`.

Only use tracks whose licence allows commercial use on social media (e.g. Pixabay Content License,
Mixkit Free License, YouTube Audio Library). Record the source and any required credit below.
